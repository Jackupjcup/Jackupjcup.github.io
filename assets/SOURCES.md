## Interface icons

`icons/xdu-crest-hd.png` is the unmodified 1870 × 1870 transparent red crest from [note286/xdulogo](https://github.com/note286/xdulogo/blob/main/西电新标志1-红色-透明.png), downloaded on 2026-09-30. That repository credits Xidian University's official crest materials and specifies AGPL-3.0. It replaces the low-resolution `icons/xdu-crest.svg` on the page.

`icons/nus-crest.svg` embeds the existing NUS logo PNG and uses an SVG viewport to show only the crest, excluding the adjacent wordmark. `icons/github.svg` shows the GitHub mark; `icons/outlook.svg` is an Outlook-blue mail icon; `icons/file.svg` is a document icon.
